## Codex

Тема работает с Claude Code или с Codex: `/new codex <путь>` создаёт сессию Codex, `/backend codex` переключает существующую тему (контекст сбрасывается). Агент по умолчанию задаётся в настройках.

Вход в Codex — один из двух способов:
- подписка ChatGPT: выполните `codex login` в терминале один раз;
- API-ключ OpenAI: укажите его в «Настройки → Агенты → Codex». Ключ используется, только если входа нет или это уже вход по ключу; вход по подписке ChatGPT не заменяется (для перехода на ключ — `codex logout`).

Права Codex задаются в «Настройки → Агенты → Codex»: песочница (`read-only`, `workspace-write` — по умолчанию, `danger-full-access`) и одобрения (`untrusted`, `on-request` — по умолчанию, `never`). Одобрения команд и правок приходят в тему кнопками, как у Claude. В итоге хода Codex показывает число токенов в сессии; фоновых задач у Codex нет.

## Qwen

`/new qwen <путь>` создаёт сессию Qwen Code, `/backend qwen` переключает существующую тему (контекст сбрасывается). Qwen работает как Codex: одобрения кнопками, `send_file`, свои вопросы с вариантами ответа, фото, досылка сообщений посреди хода (Qwen забирает их между вызовами инструментов), число токенов в итоге хода. Нужны Qwen Code 0.25+ и Node.js 22+.

Бесплатного входа Qwen OAuth (закрыт 2026-04-15) больше нет — нужен собственный доступ к модели, один из двух способов:
- собственная настройка `qwen`: выполните `qwen` в терминале и `/auth`, или заполните `~/.qwen/settings.json`, или задайте переменные окружения;
- «Настройки → Агенты → Qwen Code»: OpenAI-совместимый base URL и API-ключ (например, DashScope). Ключ хранится в системном хранилище ключей и передаётся только процессу `qwen` (как `OPENAI_API_KEY`).

Режим одобрений — `plan`, `default` (по умолчанию), `auto-edit`, `yolo`. Отправка файла инструментом хаба (`send_file`) тоже спрашивает разрешение кнопкой, как любой инструмент (кроме `yolo`). «Разрешить всегда» не предлагается.

Если задан base URL хаба, а модель в настройках пуста, `qwen` получит `OPENAI_MODEL` из окружения, в котором запущен agent-hub.

## Hermes

`/new hermes <путь>` создаёт тему с Hermes, `/backend hermes` переключает существующую тему
со сбросом контекста. Хаб запускает `hermes acp` через stdio: Telegram остаётся транспортом
agent-hub, отдельный Hermes gateway не запускается.

В «Настройки → Агенты → Hermes» задаются путь к CLI, необязательные профиль и модель. Пустой профиль
оставляет выбор самому Hermes; заданный передаётся как `--profile NAME`, без смены его
постоянного профиля. Модель применяется к сессии через ACP. Вход, провайдер, память, скиллы
и собственные MCP-серверы остаются в управлении Hermes; хаб не записывает его ключи или
конфигурацию. Для браузерных инструментов и прочих зависимостей используйте настройку Hermes.

Ответы и вызовы инструментов переводятся в события хаба. Запросы разрешений проходят через
кнопки Telegram; хаб выбирает только предложенное разовое разрешение, не «разрешить всегда».
Файлы и вопросы передаются через защищённый MCP-сервер хаба (`send_file`, `ask_user`);
вопросы ограничены пятью за вызов и четырьмя вариантами каждый. Политика того, какие
действия требуют подтверждения, остаётся политикой Hermes — хаб не включает `--yolo`.

Новые сообщения во время хода ждут в очереди хаба до его окончания: это **не досылка
между инструментами**, как у Qwen. `/stop` отменяет ход и завершает процесс. Сохранённая
сессия восстанавливается через `session/load`; ошибка восстановления не создаёт новую
сессию молча — используйте `/reset`. Токены берутся только из результата prompt, если Hermes
их сообщил; заполненность контекста не выдаётся за расход токенов.

## OpenCode

`/new opencode <путь>` создаёт тему с OpenCode, `/backend opencode` переключает существующую
тему со сбросом контекста. Хаб запускает `opencode acp` через stdio — тот же транспорт ACP,
что и у Hermes; отдельный сервер OpenCode не запускается.

В «Настройки → Агенты → OpenCode» задаются путь к CLI и необязательная модель в формате
`провайдер/модель` (например, `anthropic/claude-sonnet-4`); пустая модель оставляет выбор
конфигурации OpenCode. Модель применяется к сессии через `session/set_model`. Вход,
провайдеры и разрешения инструментов остаются в управлении OpenCode (`opencode auth login`,
`opencode.json`); хаб не записывает его ключи и конфигурацию. Агент режима (build/plan и
пользовательские) выбирает сам OpenCode — хаб его не переключает.

Ответы и вызовы инструментов переводятся в события хаба; запросы разрешений приходят
кнопками Telegram, и хаб выбирает только предложенное разовое разрешение. Файлы и вопросы
передаются через защищённый MCP-сервер хаба (`send_file`, `ask_user`). Новые сообщения во
время хода ждут в очереди до его окончания; `/stop` отменяет ход. Сохранённая сессия
восстанавливается через `session/load`; ошибка восстановления не создаёт новую сессию
молча — используйте `/reset`. Токены берутся только из результата prompt
(`usage.totalTokens`); оценочная заполненность контекста (`usage_update`) не подменяет их.

Ограничение первой версии: снимки и перенос сессий (`/save`, `/restore`, `/transfer`) для
тем OpenCode не поддерживаются — история остаётся в хранилище самого OpenCode.

Проверка готовности не вызывает модель и не доказывает вход в провайдер; это явно отмечено
на вкладке «Статус». Живой прогон с моделью и доставкой в Telegram требует отдельной проверки.
Фоновые задачи Hermes после завершения хода не поддерживаются этой интеграцией.

## Лимиты подписок

`/limits` в теме или в общем чате показывает, сколько израсходовано лимитов подписок:

```
📊 Лимиты подписок · 16.10 14:05
Claude (Max)
  5 часов     ▓▓▓▓▓▓░░░░ 62% · сброс в 17:30
  7 дней      ▓▓░░░░░░░░ 18% · сброс пн 09:00
  7 дней Opus ▓░░░░░░░░░  9%
Codex (ChatGPT Plus)
  основное  ▓▓▓▓░░░░░░ 41% · сброс в 16:10
  недельное ▓░░░░░░░░░ 12% · сброс чт 11:00
Qwen, Hermes — квоты подписки агент не сообщает
```

- Данные спрашиваются у самих CLI при каждой команде и нажатии «🔄 Обновить»; фонового опроса нет, одновременно идёт один опрос.
- Claude — короткий запуск `claude` без сообщения, запрос `get_usage`. Это экспериментальный API Claude Code, он может измениться; тогда карточка покажет последние значения из живых сессий или ⚠️. Работает при входе через подписку claude.ai. Проба не должна писать транскрипт, запускать ваши хуки и MCP-серверы; вход при `--setting-sources=` проверяется при ручной проверке.
- Codex — короткий `codex app-server`, только при входе через ChatGPT.
- Qwen и Hermes квоты подписки не сообщают.
- Каждый агент отвечает не дольше 20 с; без ответа показываются последние значения из живых сессий с пометкой «(на ЧЧ:ММ)».
- В карточке — только агенты, CLI которых найден; агент по умолчанию — первым. Время — в часовом поясе компьютера.
