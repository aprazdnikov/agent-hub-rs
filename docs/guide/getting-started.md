## Требования

- [Claude Code](https://docs.claude.com/en/docs/claude-code) **2.1.280 или новее**, вход
  выполнен (`claude` один раз запущен в терминале). Команда `claude` должна быть в `PATH`, либо
  путь к ней указывается в настройках.
- Для агента Codex (необязательно): [Codex CLI](https://github.com/openai/codex) **0.160 или
  новее** (`npm i -g @openai/codex`); вход — `codex login` или API-ключ OpenAI в настройках.
- Для агента Qwen (необязательно): [Qwen Code](https://github.com/QwenLM/qwen-code) **0.25 или
  новее** (`npm i -g @qwen-code/qwen-code`), Node.js 22+. Бесплатный вход Qwen OAuth закрыт
  с 2026-04-15 — нужен собственный доступ к модели: настройка самого `qwen` (`/auth`,
  `~/.qwen/settings.json`, переменные окружения) или OpenAI-совместимый адрес и API-ключ в
  настройках agent-hub.
- Telegram-бот и форум-группа — см. [Первый запуск](#первый-запуск).
- Для агента Hermes (необязательно): Hermes Agent с работающим ACP-адаптером;
  `hermes acp --version` и `hermes acp --check` должны завершаться успешно. Провайдер и вход
  настраиваются в самом Hermes (`hermes setup`). Контракт сверялся с установленной сборкой
  `0.21.5+9108.g61b7f95`; наличие версии не заменяет проверку ACP-возможностей.
- Для агента OpenCode (необязательно): [OpenCode](https://opencode.ai) **1.19.5 или новее**
  (`npm i -g opencode-ai@latest`); `opencode acp --version` должен завершаться успешно.
  Провайдеры и вход настраиваются в самом OpenCode (`opencode auth login`). Контракт
  сверялся с установленной сборкой `1.19.5`.
- Windows 10/11 x64, macOS (Apple Silicon или Intel), Linux x64 (glibc 2.35+).

## Установка

1. Скачайте архив своей платформы со страницы
   [Releases](https://github.com/aprazdnikov/agent-hub-rs/releases):

   | Платформа | Архив |
   |---|---|
   | Windows | `agent-hub-x86_64-pc-windows-msvc.zip` |
   | macOS, Apple Silicon | `agent-hub-aarch64-apple-darwin.app.zip` |
   | macOS, Intel | `agent-hub-x86_64-apple-darwin.app.zip` |
   | Linux | `agent-hub-x86_64-unknown-linux-gnu.tar.gz` |

2. Проверьте контрольную сумму (файл `.sha256` рядом с архивом):

   ```bash
   sha256sum -c agent-hub-x86_64-unknown-linux-gnu.tar.gz.sha256   # Linux, Git Bash
   shasum -a 256 -c agent-hub-aarch64-apple-darwin.app.zip.sha256  # macOS
   ```

3. На macOS распакуйте ZIP в отдельную пустую папку, выйдите из работающего agent-hub и
   перенесите `agent-hub.app` в `~/Applications` или `/Applications`. Не распаковывайте
   поверх существующего бандла: заменяйте его целиком. `~/Applications` не требует прав
   администратора. На других платформах распакуйте архив и запустите `agent-hub`
   (`agent-hub.exe` на Windows).

4. При первом запуске на macOS система может сообщить, что «agent-hub повреждён», или
   потребовать подтвердить разработчика. Сборки не подписаны Developer ID и не
   нотарифицированы; Gatekeeper может заблокировать загрузку с пометкой карантина.
   Совпадающая контрольная сумма подтверждает целостность загрузки, но не личность
   издателя независимо от источника. Два способа запустить доверенную сборку:

   - **Установить скриптом** — `curl`, в отличие от браузера, не навешивает карантин:

     ```bash
     curl -fsSL https://raw.githubusercontent.com/aprazdnikov/agent-hub-rs/main/scripts/install-macos.sh | bash
     ```

     Скрипт проверяет sha256, скачивает сборку под архитектуру машины и ставит `agent-hub.app`
     в `~/Applications`. Нужную версию можно передать первым аргументом или `TAG=v0.9.0`,
     папку установки — `APPS_DIR=`.

   - **Снять пометку** — если приложение уже установлено из браузерной загрузки:

     ```bash
     xattr -dr com.apple.quarantine ~/Applications/agent-hub.app
     ```

     После каждой новой загрузки через браузер пометку придётся снимать заново. Не отключайте
     Gatekeeper для всей системы.

Для `.app` обновление выполняется заменой всего бандла после выхода из приложения.

Для macOS по-прежнему публикуются прежние `.tar.gz` с исполняемым файлом и отдельные
бинарники `agent-hub-<target>`: они нужны для запуска из терминала и встроенного обновления.
При запуске из Finder окружение может отличаться от терминала; если CLI агента не найден,
укажите абсолютный путь к `claude`, `codex`, `qwen`, `hermes` или `opencode` в настройках приложения.

Дополнительные `.deb` для Debian/Ubuntu x64 и пользовательский установщик Windows x64
публикуются при успешном выполнении релизных проверок; прежние архивы остаются доступными.
Удаление приложения не предусматривает удаление пользовательских настроек и ключей.

Первый запуск на остальных платформах:

- **Windows (SmartScreen):** «Подробнее» → «Выполнить в любом случае».
- **Linux:** значок в трее показывается через StatusNotifierItem — он есть в KDE, Xfce и других
  окружениях; в GNOME нужно расширение AppIndicator. Без него приложение работает, а закрытие
  окна сворачивает его.

## Первый запуск

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username.
2. Сохраните токен вида `123456789:AA...`.
Меню команд вручную через `/setcommands` настраивать не нужно: при подключении agent-hub
полностью записывает актуальный список из исходников для настроенной группы.

### 2. Создайте форум-группу

1. Создайте группу в Telegram.
2. **Настройки группы → Темы (Topics) → включить.** Группа станет форумом.
3. Добавьте бота в группу и **сделайте его администратором** — так он видит все сообщения и
   события создания тем. Достаточно права «Управление темами».

### 3. Настройте agent-hub

При первом запуске окно открывается на вкладке **«Настройки»**.

1. Вставьте **токен бота**.
2. Узнайте ID группы и свой user id: временно впишите в `chat_id` и `user_id` любые числа
   (например `0`), укажите корень рабочих каталогов и нажмите **«Сохранить»**. Напишите
   любое сообщение в группу — бот его отклонит, а во вкладке **«Лог»** появится строка
   `rejected update` с кнопками **«Использовать chat_id»** и **«Добавить user_id»**. Нажмите
   обе и сохраните настройки ещё раз.
3. **Корень рабочих каталогов** — папка, внутри которой агенту можно выбирать рабочие
   директории (например `~/Projects`).

Бот подключится, значок в трее станет зелёным. Создайте в группе тему — бот ответит
«🆕 Новая сессия» с рабочей директорией. Напишите задачу, например:
`Посмотри структуру проекта и кратко опиши его`.

Если подключение не работает, откройте вкладку **«Статус»** и нажмите
**«Проверить настройки»**. Проверяются последние сохранённые значения, включая токен,
группу, доступные права бота, рабочий каталог и CLI выбранного агента. Если вы изменили
настройки, сначала сохраните их; несохранённые правки в проверку не входят.
