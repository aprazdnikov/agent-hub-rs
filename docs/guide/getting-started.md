# Установка и первый запуск

[Документация](../README.md) · [О проекте](../../README.md)

Для первой задачи нужны agent-hub, один настроенный агент и папка проекта.
Задачу можно поставить, проверить и продолжить прямо на компьютере. Telegram
подключается отдельно, если вы хотите работать с телефона.

- [Требования к агентам](#требования)

- [Первая задача без бота](#first-task)

## Требования

Установите один из поддерживаемых CLI на том компьютере, где будет работать хаб.
Настройте доступ к модели и проверьте, что выбранный CLI отвечает в терминале.
Для локальной задачи достаточно любого одного агента из таблицы.

| Агент | Минимальная версия и проверка | Вход и настройка |
|---|---|---|
| [Claude Code](https://docs.claude.com/en/docs/claude-code) | 2.1.280, `claude --version` | Запустите `claude` в терминале и выполните вход |
| [Codex](https://github.com/openai/codex) | 0.160.0, `codex --version` | `codex login` или API-ключ OpenAI в настройках хаба |
| [Qwen Code](https://github.com/QwenLM/qwen-code) | 0.25.0, `qwen --version` | Настройте провайдера в `qwen` через `/auth` либо укажите OpenAI-совместимый адрес и ключ в хабе |
| [Hermes](https://github.com/NousResearch/hermes-agent) | 0.21.5, `hermes acp --version` и `hermes acp --check` | Настройте провайдера через `hermes setup` |
| [OpenCode](https://opencode.ai) | 1.19.5, `opencode acp --version` | Настройте провайдера через `opencode auth login` |
| [Pi](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) | 1.6.0, `pi --version` | Подписку Codex входит `pi auth login openai-codex`; ключ Token Plan — в `~/.pi/agent/auth.json`. Хаб эти файлы не читает |

Хаб ищет CLI в `PATH`. Если в терминале команда работает, а хаб не находит
её, укажите абсолютный путь в **Настройки → Агенты → нужный агент**.
Так бывает, например, при запуске из Finder. Чтобы сохранить настройки без бота,
выберите существующую папку в **Рабочие каталоги → Корень** и оставьте пустыми
все три поля в разделе **Telegram и доступ**. [Настройка каждого агента](agents.md)

## Установка

Скачайте сборку для своей системы и соседний файл с таким же именем и окончанием
`.sha256`. Команды проверки ниже выполняются в папке загрузки. При несовпадении суммы
скачайте оба файла заново. [Сборки на GitHub Releases](https://github.com/aprazdnikov/agent-hub-rs/releases/latest)

<a id="install-windows"></a>

### Windows 10 и 11, x64

1. Скачайте **`agent-hub-x86_64-pc-windows-msvc-setup.exe`** и его `.sha256`.
   Сравните хеши в PowerShell. Совпадение даёт `True`.

   ```powershell
   $file = 'agent-hub-x86_64-pc-windows-msvc-setup.exe'
   (Get-FileHash $file -Algorithm SHA256).Hash -eq ((Get-Content "$file.sha256" -Raw) -split '\s+')[0]
   ```

2. Запустите установщик. Он ставит приложение для текущего пользователя в
   `%LOCALAPPDATA%\Programs\agent-hub` без прав администратора. Если SmartScreen
   запрашивает подтверждение для проверенной загрузки, откройте **Подробнее → Выполнить в любом случае**.
3. Откройте **agent-hub** из меню «Пуск».

Для переносной копии скачайте `agent-hub-x86_64-pc-windows-msvc.zip`, сверьте
его собственную сумму, распакуйте в папку пользователя и запустите `agent-hub.exe`.

<a id="install-macos"></a>

### macOS, Apple Silicon и Intel

Скрипт проекта сам выберет сборку для архитектуры компьютера, проверит SHA-256
и установит приложение в `~/Applications`. Выполните в терминале:

```bash
curl -fsSLo install-macos.sh https://raw.githubusercontent.com/aprazdnikov/agent-hub-rs/main/scripts/install-macos.sh
bash install-macos.sh
open "$HOME/Applications/agent-hub.app"
```

Для конкретной версии передайте тег, например `bash install-macos.sh v1.1.0`.
Переменная `APPS_DIR` задаёт другую папку установки, в которую у вас есть право записи.
[Исходный текст скрипта](../../scripts/install-macos.sh)

При установке через Finder выберите архив по процессору:

| Процессор | Архив |
|---|---|
| Apple Silicon (серия M) | `agent-hub-aarch64-apple-darwin.app.zip` |
| Intel | `agent-hub-x86_64-apple-darwin.app.zip` |

Для проверки выполните `shasum -a 256 -c agent-hub-aarch64-apple-darwin.app.zip.sha256`
или подставьте имя файла для Intel. Распакуйте ZIP в пустую папку и перенесите
`agent-hub.app` целиком в `~/Applications` либо `/Applications`.

У сборки нет подписи Developer ID и нотарификации. Если Gatekeeper помечает
проверенный архив из браузера как «повреждённый», можно воспользоваться скриптом
выше. Для уже установленной в личной папке копии команда ниже снимает пометку
карантина только с этого приложения.

```bash
xattr -dr com.apple.quarantine "$HOME/Applications/agent-hub.app"
```

Архивы `.tar.gz` и отдельные бинарники для обеих архитектур также подходят для
запуска из терминала.

<a id="install-linux"></a>

### Linux x64

Для Debian и Ubuntu скачайте **`agent-hub-x86_64-unknown-linux-gnu.deb`** и
его `.sha256`. Установите локальный пакет вместе с зависимостями:

```bash
sha256sum -c agent-hub-x86_64-unknown-linux-gnu.deb.sha256
sudo apt install ./agent-hub-x86_64-unknown-linux-gnu.deb
```

Откройте **Agent Hub** из меню приложений или выполните `agent-hub` в терминале.
Пакет устанавливает программу в `/usr/bin/agent-hub`.

Для переносной установки скачайте `agent-hub-x86_64-unknown-linux-gnu.tar.gz` и
его `.sha256`. Сборка рассчитана на Linux GNU x86-64 с графическим рабочим столом
и собирается на Ubuntu 22.04. Распакуйте в отдельную папку пользователя:

```bash
sha256sum -c agent-hub-x86_64-unknown-linux-gnu.tar.gz.sha256
mkdir -p "$HOME/.local/opt/agent-hub"
tar -xzf agent-hub-x86_64-unknown-linux-gnu.tar.gz -C "$HOME/.local/opt/agent-hub"
"$HOME/.local/opt/agent-hub/agent-hub"
```

Значок в трее использует StatusNotifierItem. В GNOME для него может понадобиться
расширение AppIndicator. [Поведение окна и трея](settings.md#окно-и-трей)

<a id="console"></a>

## Запуск без окна

Тот же хаб работает в терминале: `agent-hub --cli` открывает разговор без окна,
значка в трее и бота Telegram — для сервера, SSH или Raspberry Pi. Настройки
нужны те же, что и для окна, их заполняют один раз. Команда зависит от того, как
установлен хаб: в Linux из `.deb` это `agent-hub --cli`, в macOS — бинарник
внутри `agent-hub.app`, в Windows — WSL. Ключи `--backend` и `--dir`, команды
разговора и сборку для Raspberry Pi описывает
[консольный режим](console.md).

## Первый запуск

1. Откройте agent-hub. На экране **Входящие** в дереве слева нажмите
   **Открыть папку…** и выберите существующий каталог проекта. В узком окне
   сначала нажмите **Проекты**. Если вы сохранили корень рабочих каталогов,
   выбирайте папку в его пределах.
2. Нажмите **Новая задача**. В поле **Где запустить** выберите **Локально**.
   Раскройте строку **Проект · имя папки** и выберите установленный CLI в поле
   **Агент для новых задач**.
3. Введите в **Что поручить агенту**, например, `Перечисли файлы верхнего уровня и кратко опиши проект. Ничего не изменяй.`
   Нажмите **Начать задачу**. Откроется чат. Если агент запросит разрешение или
   уточнение, ответьте в чате или во **Входящих**.
4. Когда результат появится во **Входящих**, нажмите **Проверить**. Прочитайте
   ответ и при необходимости раскройте изменения и проверки. **Принять результат**
   отмечает задачу принятой. **На доработку** открывает чат для следующего поручения.

Чтобы подготовить поручение на будущее, нажмите **Сохранить черновик**.
Позже откройте задачу в дереве проектов и нажмите **Запустить**.
[Чат, история попыток и проверка результата](tasks.md#task-chat)

<a id="telegram"></a>

## Подключение Telegram по желанию

1. Создайте бота командой `/newbot` в [@BotFather](https://t.me/BotFather).
   Сохраните выданный токен. Меню команд хаб зарегистрирует сам при подключении.
2. Создайте группу Telegram, включите в настройках группы **Темы** и добавьте
   бота администратором с правом **Управление темами**. Для удаления тем из
   приложения дополнительно понадобится право **Удаление сообщений**.
3. В **Настройки → Рабочие каталоги → Корень** выберите папку проектов.
   В **Агенты → Общие → Агент по умолчанию** выберите установленный CLI.
   В **Telegram и доступ** заполните **Токен бота**, **chat_id группы** и
   **Разрешённые user_id** (через запятую). Нажмите **Сохранить**.
4. Когда бот подключится, создайте в группе тему. Бот ответит «🆕 Новая сессия»
   и покажет каталог. Команда `/cwd имя-папки` в теме выберет проект внутри
   корня. Напишите обычное сообщение, чтобы начать разговор с агентом.

Если ID группы и пользователя неизвестны, введите временно `0` в оба поля
и сохраните настройки с настоящим токеном. Напишите сообщение в группе и
найдите `rejected update` в **Настройки → Диагностика → Журнал**. Нажмите
**Использовать chat_id**, вернитесь в журнал и нажмите **Добавить user_id**
у своего сообщения. Удалите временный `0` из списка пользователей и сохраните
настройки. Кнопка **Проверить настройки** на странице **Диагностика → Состояние**
проверяет последние сохранённые значения, в том числе доступ к группе и права бота.

Чтобы получить на телефоне результат уже созданной задачи, выберите в теме
тот же каталог и отправьте `/task follow ID` с номером задачи из чата в
приложении. Компьютер и хаб должны оставаться включёнными.
[Продолжение задачи в Telegram](tasks.md#начать-на-компьютере-продолжить-в-telegram)

## Обновление

По умолчанию хаб проверяет новые версии при старте и раз в сутки. Способ установки
обновления зависит от запущенной копии. Завершите текущую работу и выйдите через
**Выход** в меню трея перед ручной заменой файлов. Простое закрытие окна может оставить
приложение запущенным.

| Установленная копия | Как обновить |
|---|---|
| Windows, установщик | Нажмите **Открыть релизы**, скачайте новый `-setup.exe`, сверьте сумму и запустите установщик для того же пользователя |
| macOS, `.app` | Повторно запустите скрипт установки либо скачайте новый `.app.zip`, сверьте сумму и замените весь `agent-hub.app` |
| Debian/Ubuntu, `.deb` | Скачайте новый пакет в отдельную папку, проверьте сумму и снова выполните `sudo apt install ./agent-hub-x86_64-unknown-linux-gnu.deb` из этой папки |
| Переносная копия в доступной для записи папке | Нажмите **Установить** в баннере новой версии, дождитесь проверки SHA-256 и замены бинарника, затем нажмите **Перезапустить** |

Настройки, привязки тем, задачи и файлы результатов хранятся отдельно от приложения.
Для резервной копии перед обновлением закройте хаб и сохраните каталоги с нужными данными.
[Пути к файлам](settings.md#настройки-и-файлы)
