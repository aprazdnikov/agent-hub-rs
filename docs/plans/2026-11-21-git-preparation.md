# Подготовка Git — шаг 2.2б

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Явно включённое правило проекта требует наблюдаемой подготовки Git до первого запуска задачи.
**Architecture:** ProjectRules хранит remote/base; Task — намерение и результат подготовки. Один actor записывает намерение до внешних эффектов, запускает асинхронный GitRunner и принимает результат по идентификатору операции. LocalGitRunner использует существующий управляемый процессный runner с аргументами без shell. GUI и Telegram используют один порт. Перед каждым запуском проверяется подготовленная ветка; продолжение допускает незакоммиченные результаты работы агента.
**Tech Stack:** Rust, Tokio, egui, Git CLI, существующий process-wrap.
**Spec:** docs/specs/2026-11-21-task-workflow-design.md

## Границы

Правило выключено по умолчанию. Remote и точное имя базы задаёт пользователь; рабочая ветка задаётся для задачи. Никаких stash/reset/rebase/push. Только чистый корень репозитория; база, занятая другим worktree, запрещена. Полученная база должна быть потомком локальной; локальная база впереди remote тоже требует ручного решения. Создание только новой ветки. Повторная подготовка доступна лишь до попыток; при частичных эффектах пользователь проверяет Git и выбирает новое имя. Результат успешной подготовки содержит SHA. Отдельный запуск модели после подготовки. Изменения посторонних процессов между проверками нельзя исключить; перед опасными шагами повторяются проверки, update-ref использует ожидаемый SHA.

## Review Focus

- Грязное дерево, существующая ветка, неверный регистр базы, отсутствующий remote: никаких скрытых исправлений.
- Сеть/таймаут/остановка после части эффектов: объяснение, сохранённый статус, без повтора и модели.
- Старый ответ/смена темы/редакции: не запускает модель в новом контексте.
- Конкурирующая работа хаба: запрещена во время подготовки; начало подготовки запрещено при занятом хабе.
- Старые файлы и восстановление заполненной книги сохраняют историю.
