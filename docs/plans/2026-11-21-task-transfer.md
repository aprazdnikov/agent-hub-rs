# Передача сохранённой задачи — план этапа 2.1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Статус: шаг 2.1 реализован, автоматически проверен и прошёл независимое ревью с исправлением важных замечаний. Живой чек-лист ещё не подтверждён.

**Goal:** Передавать задачу другому агенту без потери ID, результатов и авторства попыток; видеть отправляемое поручение до запуска.

**Architecture:** TaskBook владеет переназначением и ревизиями. Новый исполнитель сохраняется до ответа GUI/Telegram; модель не вызывается. Один генератор текста используется предпросмотром и фактическим запуском.

**Tech Stack:** Rust, serde, egui, существующий actor и sidecar.

**Spec:** [Развитие задач](../specs/2026-11-21-task-workflow-design.md), этап 2, первая самостоятельная поставка. Правила проекта и проверяемая подготовка Git остаются этапом 2.2, GUI без бота — этапом 3.

## Global Constraints

- Сохранить прежние ID, ревизии, шаги и результаты; отсутствие исполнителя в старом запуске означает исходного исполнителя задачи.
- Не менять активную, архивную, принятую или отложенную задачу; последние два состояния сначала вернуть в работу.
- Смена агента не запускает модель, не переносит разрешения и не меняет тему.
- Старые заполненные файлы остаются читаемыми; переполнение при переназначении отказывает до записи.
- Продолжение по-прежнему требует явного следующего шага и темы того же проекта с назначенным агентом.

## Review Focus

- Старые попытки без поля backend не должны менять авторство при повторном переназначении.
- Устаревшая ревизия или сбой записи не должны менять видимого агента.
- Чужой проект не может ни переназначить, ни прочитать предпросмотр.
- Предпросмотр и фактический текст запуска должны совпадать, включая переносы и прежний результат.
- Смена темы и фоновое обновление не должны отправить случайное назначение или сбросить ввод.
