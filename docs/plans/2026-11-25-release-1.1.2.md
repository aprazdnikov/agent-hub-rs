**Goal:** Публикация v1.1.2 с тремя доработками: надёжная синхронизация исчезнувших тем,

  соответствия тега версии workspace.

  [обзора](2026-11-25-improvements-overview.md) в `main`, затем релизный коммит.
- Машина без `gh`/токена: проверка через публичный API curl; PR создаёт владелец по
  compare-ссылке.
