# Диагностика первого запуска

Статус: реализовано и проверено локально; проверка с реальным Telegram остаётся
открытой перед выпуском.

## Цель и границы

Помочь подключить существующего Telegram-бота и найти причину ошибки, не отправляя
агенту задачу и не меняя настройки автоматически. Проверяются сохранённые настройки;
несохранённые изменения обозначаются отдельно. Отсутствующая группа не мешает
запуску бота, поэтому ID по-прежнему можно обнаружить в журнале.

## Выполнено

- [x] Окно состояния показывает отдельный повторяемый отчёт: токен, доступность и тип
  чата, доступное право администратора управлять темами, корневой каталог и версию
  выбранного CLI. Неполученные сведения обозначаются как непроверенные.
- [x] Неверный токен, недоступный чат и сетевые или неизвестные ошибки различаются;
  сообщения содержат следующий шаг. Отчёт не утверждает, что проверка CLI
  подтверждает вход или работу модели, и не включает текст ответа или URL с токеном.
- [x] Сетевые запросы диагностики ограничены общим сроком; поиск CLI и проверка
  каталога ограничены по времени и числу одновременно занятых файловых workers.
  Остановка и сохранение настроек отменяют незавершённую проверку.
- [x] Запуск обрабатывается одновременно с командами supervisor: остановка, выход,
  диагностика и изменение настроек доступны во время запуска. Старый запуск при
  смене настроек отменяется; повторные подключения и чтение очереди сохраняются.
- [x] Добавлены локальные тесты Telegram-ответов, тайм-аута, недоступного каталога и
  CLI, смены настроек и отмены запуска, завершения CLI-процесса, а также сценария
  определения ID при недоступной группе.

## Проверка перед выпуском

- [x] Общий прогон: 1784 теста прошли, 13 пропущены; Clippy, форматирование,
  `git diff --check` и сборка приложения прошли на Linux.
- [ ] Проверить работу с реальным Telegram, включая форум и права администратора.

Проверка прав ограничена сведениями Bot API: неуспешный ответ о правах не считается
успехом. Для создания темы в супергруппе бот должен быть администратором с правом
управления темами; общие права участников этого не подтверждают. Проверка каталога
не гарантирует будущую доступность сетевого диска. Зависший системный файловый
вызов при запуске нельзя принудительно прервать, но он удерживает единственный слот;
каждая попытка ограничена десятью секундами, включая ожидание слота. Сохранение
настроек выполняется отдельным сериализованным worker; его ограничения
описаны в `2026-11-06-settings-save-resilience.md`.

Проверки дополнительных CLI ограничены пятью секундами: корректный, но медленный CLI
может временно показываться недоступным. Выбранный CLI и другие проверки используют
раздельные ограниченные workers; локальные тайм-ауты запускают повтор с backoff.
