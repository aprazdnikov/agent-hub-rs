# Правила проекта — план шага 2.2а

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Пользователь сохраняет правила один раз для каталога; каждый ручной запуск получает видимую редакцию правил и сохраняет её в истории.

**Architecture:** Правила и задачи сохраняются одним actor в существующий TaskBook. Ответ порта содержит задачи и правила выбранного проекта. GUI держит отдельный черновик, который не заменяется фоновым чтением. В истории попытки хранится снимок включённых правил.

**Tech Stack:** Rust, serde, egui, существующий actor и файловый store.

**Spec:** docs/specs/2026-11-21-task-workflow-design.md

## Границы

Git-подготовка остаётся следующим отдельным шагом 2.2б: этот шаг добавляет инструкции, а не исполнение Git-команд. Правила по умолчанию выключены. Нет commit/push, новых зависимостей или второго writer. Старый формат читается; пустые новые поля не увеличивают старые файлы.

## Review Focus

- Старая редакция при сохранении и запуске: отказ без побочных эффектов.
- Фоновое чтение при вводе: черновик и фокус сохраняются.
- Другой проект: отдельные правила, прежний черновик не переносится.
- Изменение правил после запуска: история сохраняет прежний текст.
- Ошибка сохранения: не подтверждать изменение, не запускать модель.

## Реализация

- [x] Core: ProjectRules (revision, enabled, text), до 16 КиБ текста и 100 проектов; обновление с expected_revision; Run.rules — неизменяемый снимок; единый preview_with_rules. Тесты конфликтов, изоляции, выключения, истории и старого формата.
- [x] Actor: ответ задач содержит правила, чтение и сохранение через тот же порт; GUI-запуск проверяет ожидаемую редакцию. Telegram `/task rules`, `/task rules-set РЕВИЗИЯ on|off | ТЕКСТ`. Тесты сохранения и точного prompt.
- [x] GUI: раскрываемый раздел «Правила проекта», явное включение и сохранение, индикатор несохранённого черновика; предпросмотр и история содержат правила. Проверка ввода при обновлении.
- [x] Документация и проверка: тесты затронутых пакетов, fmt, Clippy, сборка; инструкция ручной проверки. Независимая финальная проверка изменений этого шага.
