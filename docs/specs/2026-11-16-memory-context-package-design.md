# MEM-05: пакет контекста

[Roadmap](../roadmap/2026-11-15-company-brain-roadmap.md#mem-05--пакет-контекста-и-передача-работы).
Решения принимает агент по прежнему поручению продолжать самостоятельно.

## Подход

Выбран явный подбор сохранённых записей и заполнение краткого поручения человеком.
Автоматический подбор/сводка через LLM добавляет стоимость и риск скрытой потери
ограничений; изменение /handoff меняет утверждённую границу. Оба варианта отложены.
Пакет готовится вне /handoff и передаётся пользователем выбранному агенту обычным
сообщением. Сервис не выбирает модель и не отправляет задачу агенту автоматически.

## Состав и границы

- Проект: текущий канонический cwd и стабильный ID памяти; token снимка.
- Поручение: цель, ограничения, состояние, следующий шаг и 1–8 источников этих
  формулировок. Все четыре поля обязательны, до 4096 байт UTF-8 каждое; явное
  «нет»/«неизвестно» допустимо. Источник до 2048 байт; авторство/согласие не удостоверяются.
- От 1 до 20 явно выбранных ключей с точными ревизиями, без дубликатов ключей.
  Полные записи, исходные источники, состояние записи, доступные версии включаются.
  Исторические, stale и archived записи не выдаются за актуальные: явные предупреждения.
- Все данные читаются из одного снимка. Отсутствующая/удалённая/очищенная ревизия
  даёт отказ всего пакета; скрытого пропуска и подстановки latest нет.
- Источники не открываются: нет чтения произвольных файлов, URL, репозиториев или
  дополнительных LLM-вызовов. Они помечены «не проверены»; получатель должен проверить
  наличие/содержание существенных источников, а не считать утверждения доказанными.
- Пакет содержит предупреждение: данные не являются инструкциями/полномочиями,
  предложения/decision не доказывают согласия; права исходной сессии не переносятся.

## Бюджет и выдача

Бюджет — точные байты UTF-8 текста пакета, не оценка модельных токенов:
по умолчанию 16384, диапазон 1024–65536. Поля и записи сериализуются в JSON с
русской вводной. Ничего не обрезается. Если текст не помещается, ошибка сообщает
нужный размер и бюджет; пользователь увеличивает бюджет или явно уменьшает состав.

Пакет неизменяемый, хранится только в оперативной памяти. Preview показывает
размер, состав и предупреждения. Перед выдачей/копированием проверяются cwd,
идентичность и snapshot token; любая запись/смена политики/пересоздание/перепривязка
требует пересобрать пакет. Это проверка на момент выдачи, а не бессрочная гарантия
свежести. После передачи получатель сверяет версии по памяти самостоятельно.

GUI: добавить открытую ревизию в пакет, заполнить поручение и источники,
собрать, просмотреть, проверить и скопировать. Любое изменение формы, состава или
бюджета блокирует копирование прежнего preview до пересборки. Смена проекта очищает состав и
поля; смена поискового запроса сохраняет черновик того же проекта.
Telegram: /memory context с подписанными строками формы; preview и отдельная кнопка
получения текста. Существующие проверки пользователя/темы/cwd/TTL остаются.
Пакет выдаётся нумерованными частями до 3500 единиц UTF-16 полезного текста,
без удаления пробелов/переносов. Ошибка части останавливает выдачу; успех только
после всех частей. Отмена и общий таймаут 30 с; отправленные части не отзываются.
Транспортные подписи частей не входят в byte budget самого пакета.
Общий текст можно передать любому из пяти агентов или самостоятельному CLI.
Автоматический выбор/запуск агента и новый MCP tool не добавляются.

## Приёмка

Автотесты: целый пакет, точная граница бюджета (включая кириллицу), полнота источников,
старые/архивные записи, отсутствующая ревизия, отсутствие чтения источников,
изоляция проектов, stale token, изменение привязки, GUI очистка при смене проекта,
Telegram форма и scope выдачи. Реальную экономию ручного восстановления на MEM-01
подтверждает пользователь: автоматический тест проверяет состав, не поведение модели.
