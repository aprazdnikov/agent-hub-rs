# v1.2.0 — агент Pi и консольный режим

Agent Hub теперь поддерживает Pi в десктопном приложении и Telegram. Хаб также можно запустить в терминале для работы по SSH или на машине без графического сеанса.

## Агент Pi

- Установите Pi CLI и авторизуйтесь в нём. В разделе «Настройки → Агенты → Pi» можно указать путь к CLI, модель и режим одобрений. Настройки подписок и ключи остаются в Pi.
- В Telegram команда `/new pi <путь>` открывает новую сессию. Команда `/backend pi` переключает агента в текущей теме со сбросом контекста.
- Для Pi доступны выбор модели, уровень размышления, уточнения во время хода и запросы разрешений на команды и запись файлов.

[Настройка Pi](https://github.com/aprazdnikov/agent-hub-rs/blob/v1.2.0/docs/guide/agents.md#pi)

## Консольный режим

```bash
agent-hub --cli --backend pi --dir ~/projects/my-project
```

- `--cli` и `--tui` запускают разговор в терминале без окна, трея и Telegram-бота. Можно выбрать любого поддерживаемого агента.
- Набирайте сообщения обычными строками. `/stop` прерывает ход, `/help` показывает команды, `/quit` завершает работу.
- Для запуска на Raspberry Pi предусмотрена сборка из исходников для 64-битной ОС. В Windows для консольного режима используйте WSL, где поддерживается обычный Linux-бинарник соответствующей архитектуры.

[Руководство по консольному режиму](https://github.com/aprazdnikov/agent-hub-rs/blob/v1.2.0/docs/guide/console.md)

## Обновление с v1.1.2

Завершите активные запуски и закройте хаб перед установкой. Сохраните копию настроек и данных, если планируете вернуться к предыдущей версии. Сначала установите Pi CLI и войдите в него, если хотите использовать новый бэкенд.

В каталоге загрузки проверьте сумму перед установкой. Подставьте имя выбранного файла.

- **Linux** — `sha256sum -c agent-hub-x86_64-unknown-linux-gnu.deb.sha256`. Ожидаемый результат — `OK`.
- **macOS** — `shasum -a 256 -c agent-hub-aarch64-apple-darwin.app.zip.sha256`. После `OK` распакуйте архив и замените весь `agent-hub.app`.
- **Windows PowerShell** — следующие команды вернут `True` при совпадении.

  ```powershell
  $file = 'agent-hub-x86_64-pc-windows-msvc-setup.exe'
  $expected = ((Get-Content -Raw -LiteralPath "$file.sha256") -split '\s+')[0]
  (Get-FileHash -Algorithm SHA256 -LiteralPath $file).Hash -eq $expected
  ```
