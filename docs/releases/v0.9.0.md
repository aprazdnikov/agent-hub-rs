# v0.9.0 — новые настройки и системные темы

Обновили окно agent-hub: настройки теперь разделены по задачам и агентам, а светлая и тёмная темы следуют настройкам системы. Подробное руководство вынесено из README в отдельные страницы, сайт дополнен актуальными возможностями приложения.

## Настройки

- **Семь разделов вместо длинной формы.** Telegram и доступ, рабочие каталоги, агенты, проекты, действия, голосовые сообщения, запуск и обновления получили свои страницы.
- **Отдельная страница для каждого агента.** Общие параметры и таймауты вынесены отдельно; поля и история отмены ввода изолированы между редакторами агентов.
- **Правки сохраняются при переходах.** Можно отредактировать несколько разделов и применить всё вместе. Кнопки «Сохранить» и «Отменить изменения» всегда доступны внизу окна.
- **Ошибки проще найти.** Счётчики у разделов и агентов показывают неверно заполненные поля. Кнопка «Исправить ошибки» открывает страницу с первой ошибкой, в том числе в скрытом разделе.
- **Компактная навигация.** В узком окне боковое меню заменяется выпадающим списком; содержимое прокручивается отдельно от кнопок сохранения.

## Оформление

- Новые светлая и тёмная палитры, обновлённые вкладки и представление статуса.
- Тема автоматически меняется вслед за системой без перезапуска приложения. В Linux используется XDG Desktop Portal; переключение требует его поддержки окружением рабочего стола.

## Документация и сайт

- Краткий README с быстрым стартом и ссылками на восемь разделов руководства: установка, Telegram, агенты, проекты, сообщения, сессии, настройки и безопасность.
- Сайт описывает новый интерфейс и возможности предыдущего релиза: профили проектов, голосовые задачи, передачу между агентами, прогресс, очередь доставки и пользовательские действия.

## Исправления

- **Проверка автозапуска на macOS.** Исправлена ошибка `Invalid Service Management response`: ответ системного API корректно распознаётся и в строковом, и в числовом виде. Проверка больше не зависит от констант, недоступных через JavaScript-мост macOS; неизвестные ответы по-прежнему не считаются подтверждением автозапуска.
- **Остановка пользовательских действий на macOS.** Устранён ложный `PermissionDenied`, когда команда уже завершилась после сигнала остановки. Оставшиеся процессы по-прежнему останавливаются, а реальные ошибки доступа не скрываются.

## Обновление

Формат настроек не меняется: существующая конфигурация продолжает работать. Автозапуск, голосовые задачи и права агентов управляются прежними настройками.
