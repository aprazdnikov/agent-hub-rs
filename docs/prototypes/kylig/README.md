# Agent Hub на Kylig UI

[Открыть карту переходов](preview.html#map) · [Входящие](preview.html) · [Первый запуск](preview.html#setup) · [Задачи](preview.html#tasks) · [Настройки](preview.html#settings) · [Агенты](preview.html#agents) · [Действия](preview.html#actions) · [Политика очистки](preview.html#memory-tools) · [Журнал](preview.html#logs). Скачанный HTML-файл открывается локально в современном браузере с WebGL. Для просмотра нужны только этот файл и браузер. Внутри работает та же Rust-программа, что в нативном окне.

Макет предназначен для согласования экранов и переходов. Проекты, ответы агентов и операции с Telegram, файлами и настройками представлены демонстрационными данными в памяти. Поля для подключения рассчитаны на вымышленные значения.

## Маршруты для просмотра

Начните с входящих. Верхняя навигация доступна на каждом экране. **Карта переходов** открывает также первый запуск, меню трея и сброс демонстрационных данных. Кнопка темы в шапке позволяет сравнить обе палитры.

| Сценарий | Что попробовать |
| --- | --- |
| Первый запуск | Открыть карту, выбрать первый запуск и пройти локальную настройку или настройку Telegram |
| Входящие | Ответить на вопрос, решить запрос разрешения, открыть результат, принять или вернуть на доработку |
| Задачи | Создать поручение, выбрать исполнителя, подготовить ветку и поставить запуск в очередь. Потянуть границу между деревом и задачей. В чате отправить уточнение кнопкой или Ctrl+Enter (⌘+Enter на macOS), открыть проверки из ответа |
| Проверка результата | Посмотреть сводку, изменения, проверки, файлы и историю попыток. Открыть ошибку запуска и попробовать снова |
| Темы Telegram | Отфильтровать темы по агенту, открыть карточку темы, изменить режим памяти. Вернуться к списку и проверить пустой ответ или ошибку синхронизации |
| Память | Выбрать проект и запись, сравнить ревизии, подготовить контекст, посмотреть импорт и решения конфликтов |
| Настройки | Пролистать стопку агентов или выбрать имя, отредактировать параметры и сохранить. Открыть профиль проекта, автозапуск или обновление |
| Действия | Открыть команду, связать её с проектом и сохранить. На вкладке «Меню /actions» запустить и остановить демонстрацию кнопки Telegram |
| Журнал | Из диагностики открыть журнал, найти событие по тексту или ID, выбрать уровень и скопировать найденные строки. Прокрутка вверх приостанавливает автопрокрутку |
| Трей | Остановить и запустить демо-бота, открыть главное окно или подтвердить выход |

## Запуск из исходников

Из корня репозитория:

```sh
cargo run --locked -p hub-ui-prototype
```

Браузерная и нативная версии используют `kylig-ui 0.12.1`, `eframe/egui 0.37` и общую с приложением настройку палитры. Прототип находится в отдельном пакете workspace.

Для пересборки браузерного файла нужны Node.js, целевая платформа WebAssembly и CLI версии `wasm-bindgen` из `Cargo.lock`:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.129 --locked
node docs/prototypes/kylig/build-preview.mjs
```

Путь к уже установленному CLI можно передать через переменную `WASM_BINDGEN`.
