Поручите задачу Claude Code, Codex, Qwen Code, Hermes, OpenCode или Pi. Агент работает в папке проекта на вашем компьютере. Подключите Telegram, если хотите отвечать с телефона.

Переписка по задаче

Выберите задачу в дереве проектов. В чате видны поручение, ответ агента и ссылка на результат. Здесь же можно отправить уточнение.

Что ждёт решения

Ответьте на вопрос агента, разрешите действие или проверьте результат. Фильтр по проекту поможет найти нужную карточку.

Проверка результата

Откройте изменения в результате задачи. Выберите строку, чтобы оставить замечание, затем примите работу или отправьте её на доработку.

Кто выполняет задачу

Выберите карточку агента, чтобы настроить его параметры. В общих настройках назначьте исполнителя и ревьюера для новых задач.

Как организовать работу в проекте

Проверка и ревью

В правилах проекта выберите исполнителя, команду проверки и ревьюера. Если тесты упадут, исполнитель получит одну попытку исправления. После успешной проверки ревьюер посмотрит изменения, а результат примете вы.

Очередь задач

Ставьте задачи в очередь, пока агент занят. В основной папке они выполняются по одной. В отдельных рабочих деревьях Git можно запустить две задачи параллельно. Руководство по задачам

Общая память

Включите память проекта, чтобы агенты могли сохранять принятые решения, ход работы и ссылки на источники. Эти записи доступны в новых задачах и при смене агента. Как работает память

Первый запуск без Telegram

  1. Настройте одного агента

    Установите консольную версию выбранного агента, настройте доступ к модели и проверьте запуск в терминале. Настройка агентов

  2. Установите agent-hub

    Скачайте сборку для своей системы, сверьте SHA-256 и откройте приложение. Инструкция по установке

  3. Откройте папку и поставьте задачу

    В дереве проектов нажмите «Открыть папку…», затем «Новая задача». Выберите «Локально» и агента, введите поручение и нажмите «Начать задачу».

Если нужен Telegram

Создайте бота через @BotFather. Добавьте его в группу с включёнными темами и назначьте администратором с правом «Управление темами».

В настройках agent-hub укажите корень рабочих каталогов. В разделе «Telegram и доступ» заполните токен, ID группы и ID пользователей, которым разрешён доступ. Сохраните настройки.

Оставьте приложение запущенным. В теме того же проекта отправьте /task follow ID, подставив номер задачи из чата. Вопросы и результаты этой задачи появятся и на телефоне.
